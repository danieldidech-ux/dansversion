# Illinois Filing Tracker backend

The live service checks official RSS every 60 seconds and stores filings in SQLite on a 1 GB Render disk. One Starter web service ($7/month) and disk ($0.25/month) remain the infrastructure footprint. Existing main branch and ILGA service are separate.

## Run and test

    pip install -r requirements.txt
    python -m unittest discover -s tests -v
    gunicorn --workers 1 --threads 4 --bind 0.0.0.0:8000 'app:create_app()'

Use DATA_DIR for storage; production requires REQUIRE_PERSISTENT_DISK=1. One worker is intentional: a filesystem lock prevents duplicate collector/dispatcher ownership. Both threads start in the serving process, including with Gunicorn preload. Collection is independent of push dispatch, so a slow Apple request cannot block source polling. Health checks cover both threads and the database.

Successful polling uses 60 seconds between completed checks. Source failures back off 10, 20, then 30 minutes. Feed GUIDs deduplicate filings; metadata corrections do not enqueue new alerts. Initial baseline is suppressed. Filings, source checkpoint, and notification outbox are committed atomically. Queue entries also deduplicate across individual and group subscriptions. Source overlap gaps remain flagged until reviewed.

## API

Public: `/v1/status`, `/v1/filings`, `/v1/filings/<seq>`, `/v1/committees?q=...`, `/v1/categories`, `/healthz`, `/readyz`. Filing pagination uses `before` or `after` discovery sequence; committee pagination uses `after` ID.

Private endpoints require `Authorization: Bearer <64 lowercase hex characters>`: a cryptographically random 32-byte installation secret generated by the client, stored in Keychain, and never logged or bundled. The server stores only SHA-256 of the secret. Treat possession of it as access to that installation.

- `POST /v1/installations`: idempotent registration of this credential.
- `GET /v1/me`: watchlist and notification configuration state.
- `PUT /v1/me/watchlist`: `{ "committees": ["internal-key"], "categories": ["verified-category-id"] }` replaces the watchlist; unknown committees/unverified categories are rejected.
- `GET /v1/me/filings?before=<seq>`: paginated union of followed committees and verified groups, including historical filings.
- `PUT /v1/me/push`: `{ "enabled": true, "token": "APNs hex token", "environment": "sandbox" }`; false disables delivery and removes queued pending alerts.
- `DELETE /v1/me`: deletes installation, token, watchlist and outbox. Public filing data remains.

Maximum request body 64 KB; maximum 1,000 committees per watchlist. Persisted fixed-window rate limits: 100 new registrations globally/hour and 600 authenticated requests/installation/hour. These are initial prototype limits, not scalable public abuse protection. Before broad release, add attestation and tune limits from observed traffic.

## Apple push configuration

Set these as private Render environment variables, not repository files:

- `APNS_TEAM_ID`: Apple Developer team ID.
- `APNS_TOPIC`: app bundle ID matching Xcode.
- `APNS_SANDBOX_KEY_ID` / `APNS_SANDBOX_PRIVATE_KEY`: sandbox key ID and `.p8` contents.
- `APNS_PRODUCTION_KEY_ID` / `APNS_PRODUCTION_PRIVATE_KEY`: production key ID and `.p8` contents.

Keys can be environment-scoped; configure each environment separately. Actual newlines or literal `\n` in the private-key value are supported. With no credentials, no APNs calls occur. `/v1/me` reports whether at least one environment is configured; the iOS settings screen keeps activation disabled until then. Configure sandbox before Debug device tests and production before TestFlight. Merely configuring a key does not verify its validity.

A separate dispatcher checks the outbox every five seconds, sends via HTTP/2 and ES256 JWTs, retries transport errors/429/5xx, disables invalid/unregistered tokens, and expires alerts older than 24 hours. It uses a stable per-filing APNs collapse ID to reduce duplicate displays after ambiguous transport failures. Exactly-once delivery is not guaranteed: a crash after Apple accepts a notification but before recording success can cause retry. Apple delivery itself is best-effort. Opt-out cancels pending work; an already-in-flight notification cannot be recalled.

## Category accuracy

Five categories exist as disabled review entries: House Democrats, House Republicans, Senate Democrats, Senate Republicans, Caucus committees. `category_members` supports many-to-many membership and `categories` stores review date/source. Legislative membership must include current sitting legislators and all relevant current-cycle candidates, including when not present in recent RSS. Do not set `verified=1` until full mapping/coverage has been reviewed. Current committee IDs are normalized-name hashes, not official IDs: full directory ingestion and official-ID alias mapping are still required before activating these groups. Individual follows currently cover names observed in the monitored feed only.

## Retention and remaining release gates

Source checks and completed delivery metadata are retained for 30 days. Daily SQLite-native backups retain three dates on the same disk; deleted personal data can remain there until rotation. Off-host backups, restoring deleted-data tombstones during disaster recovery, operator alerting, load testing, public privacy/support pages, and App Store verification remain release work. Long-term public launch readiness and an end-to-end Apple notification have not yet been established.

Native iPhone source and Xcode project: `../ios/`. No Apple private keys are included.

## Native A-1 report contents

`GET /v1/filings/<seq>/contents` requires the existing installation bearer credential.
The reader retrieves the exact stored A1List URL with its FiledDocID, validates the
committee and report type plus the printable document's matching FiledDocID, and
converts every row into structured contribution data. Values use decimal arithmetic;
monetary versus in-kind labels come directly from the report. The native app displays
amount, contributor, received date, description, vendor and expandable addresses.

Successful responses cache on the existing SQLite disk for one hour; failures cache
for 30 seconds. Two concurrent report downloads are allowed, with a 12-second socket
timeout and 2 MB body limit. This does not alter the 60-second RSS collector. Existing
per-installation request limits apply. No additional hosted service is required.

This first parser supports the verified, unpaginated seven-column A-1 table. PDFs,
quarterly reports and other formats return `unsupported`; changed, mismatched,
paginated, empty or malformed tables return `unavailable` without fabricated or
partial totals. The app keeps the official report link below its native contents.
The real public fixture in `tests/fixtures/rezin-a1.html` is filing 1020512, retrieved
September 22, 2026, with navigation and ASP.NET state removed.

Run verification with `PYTHONPATH=tracker python -m unittest discover -s tracker/tests -v`.
